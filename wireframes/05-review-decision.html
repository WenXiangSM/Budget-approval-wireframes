2. Requirement View

Description of request
Upgrade the agency's Records Management System (RMS) from Version 3.2 to Version 5, including replacement of the two application servers and the storage array that reached end-of-support on 30 Jun 2026. Covers software licences for 450 named users, implementation and data migration services, user training and first-year maintenance.
Justification
RMS Version 3.2 is no longer supported by the vendor and does not meet current security requirements identified in the last internal audit. The current storage array is at 91% capacity and cannot accommodate the FY2026 digitisation intake of approximately 18 TB. Deferral would require an interim support contract of about S$160,000 and carries an unmitigated data-loss risk.
